水と電気のサイエンス

手で押さずに、スイッチON。
電気の流れは、どう変わる？

MOSFET（モスフェット）は、電気の合図で操作できるスイッチ。
指で押すかわりに、電圧をかけてON・OFFを切りかえます。
まずは、水門で水の流れを変える模型を動かしてみよう。

今日のゴール：「合図」と「動かす電源」の違いを説明できる
水門で実験3つの役割本物のしくみクイズ

電圧：電気を流そうとするはたらき。水の高さの差にたとえられます。
電流：電気の流れの大きさ。1秒間に流れる水の量にたとえられます。

模型の数字と、本物の違い

この模型は、3Vで開きはじめ、7Vでよく通る設定です。電流や回転の速さも説明用の目安で、実際の部品の測定値ではありません。後のmicro:bitの実験には、約3Vの合図で十分にONになる別の部品を選びます。画面の青い粒は「電流の向き」を表し、電子そのものではありません。

電圧は、いつも「差」で考える。合図になるのは、ソースを基準にしたゲートの電圧。 これを VGS（ブイ・ジーエス）と書きます。
たとえば、Sが0V、Gが3Vなら、差は3V。Sが2V、Gが5Vでも、差は同じ3Vです。Vはボルトという単位です。

3

覚えることは、この3つ

タップすると、続きが出てきます。「ためす」ボタンで、上の実験パネルが動きます。

水門が少し開けば、水は少しずつ流れはじめます。でも、それだけで水車が勢いよく回るとは限りません。
MOSFETにも、電流が流れはじめる目安の電圧があります。これがしきい値（しきいち）です。 「流れはじめる電圧」と「モーターを動かすのに十分な電圧」は別。十分にONにする電圧は、部品の説明書で確認します。
水門が全開でも、水を流そうとする高さの差がなければ、水車は回りません。
MOSFETも、道を開くだけではモーターを動かせません。ゲートへの合図は「流れていいよ」、電源は「動かすエネルギーを届ける係」です。MOSFETがエネルギーを作り出すわけではありません。
オレンジの水は、水門を操作するための水。青い本流とは混ざりません。水位を保てれば、注ぎ続けなくても水門を開けておけます。
ゲートも、電圧を保っている間は電流がほとんど流れません。ただしON・OFFを切りかえるときには、電気をためたり取り出したりする電流が流れます。
🔬

ほんとうの中では、浮きも水門も動きません。
ゲートに電圧をかけると、うすい膜（まく）の向こう側にも電気の力がはたらきます。この力で、もともと部品の中にある電子が集まり、電流が通る道ができます。 「離れた場所にも電気の力がはたらく」点は、こすった下じきが髪の毛を引きつける現象と共通しています。力のはたらくようすを電界（でんかい）といいます。
ゲートと通り道の間には電気を通しにくい膜があり、電子がゲートから膜を通り抜けて集まるわけではありません。

発展：プログラムでモーターを動かす

micro:bit（マイクロビット）は、プログラムで合図を出せる小さなコンピューターです。まずは「合図 → MOSFET → 流れが変わる」が分かればOK。先にクイズへ進む

写真・配線・プログラムを見てみる（先生と一緒に）

これが、使う装置 写真

この教材で紹介する装置の写真です。番号の場所を見くらべて、合図を出す部品と、動く部品を探そう。

🔍

写真から、つながり方が読みとれます。 Groveポートの刻印は左から「GND・3V3・P3-P0」。さしてあるケーブルの色も左から 黒・赤・白・黄。 つまり 黄＝P0（合図）／白＝P3（この基板では未使用）／赤＝3V3（電源）／黒＝GND。 下の図と、同じつながり方です。

じっさいの装置 信号の道すじ

合図はmicro:bitのP0からMOSFETのGへ。モーターを動かす電流は電源から流れます。2つの道をたどろう。

Groveケーブルの4本は、それぞれ役目がちがいます。

  1. 黄：P0の合図ゲートへ。電圧で合図を送る線。切りかえるときには、ゲートに電気を出し入れする電流も流れる。
  2. 白：もう1本の信号（P3）この基板では使っていない。ポートの刻印「P3-P0」の、P3のほう。
  3. 赤：電源（3V3）モーターを回す電流は、こちらから来る。P0（合図）からではない。もとは、マイクロビットにつないだ USB の電気。
  4. 黒：GNDもどり道。ソースにつながって、合図と電流の共通の基準になる。
💡

第1節の「合図」と「電源」を思い出そう。 オレンジの操作用タンク（黄の線）と、本流のタンク（赤の線）は別。 MOSFETが、電源からモーターを通る電流の道を開け閉めします。

なぜ、MOSFETをはさむのか 直結できない理由

マイクロビットの端子は、力もちではありません。

くらべるものどれくらい
マイクロビットの端子1本が出せる電流→ 合図を出すための小さな電流。使える量は機種や設定で変わる
ボード全体（エッジコネクタ）の合計→ 機種・電源・本体の動作で変わる。モーター用に全部使えるわけではない
小さな振動モーターが必要とする電流→ 機種によって違う。回りはじめや、回転が止められたときにも注意
🚪

だから、端子でモーターを直接まわそうとしてはいけません。 MOSFETは「電圧の合図で、電流の道を開ける水門」。 マイクロビットは水門を開けるだけ、モーターを回す水は電源から来る——この役割分担が、制御のきほんです。
なおこの装置では、そのモーターの電流も USB からマイクロビットを通ってきています。 MOSFETを入れても、電源から取り出せる電流の上限は増えません。先生が機種とモーターの仕様を確かめてから使います。
単位メモ：1A（アンペア）＝1000mA（ミリアンペア）。

この装置のつなぎ方 Nチャネル・下側スイッチ

アタッチメント基板の中身です。モーターから電源へ戻る道にMOSFETを入れます。GND（グラウンド）は、この回路の電圧を比べる基準です。電源も、マイクロビット（USB）から。

  1. P0 → ゲートゲートを操作する線。切りかえ時には小さな電流も流れる。配線や保護抵抗は、部品に合わせて選ぶ。
  2. 3V → モーター → ドレインモーターを回す電流の道。もとは USB から来ている電気。
  3. ソース → GNDもどり道。マイクロビットの GND とつながって、合図と電流の共通の基準になる。
  4. ゲート → 10kΩ → GND基板の裏に入っている「プルダウン抵抗」。P0がまだ何も出していない間、ゲートを 0V に引きとめておく係。
  5. 電源は USB からこの装置では、モーターの電流もマイクロビットを通っている。だから、つなげるモーターの大きさに上限がある（ひとつ上の表）。

10kΩは、操作用タンクの「底の穴」 誤作動を防ぐ

基板の裏に入っている、地味だけれど大事な部品です。水の模型で考えると、はっきりします。

ゲートには、少しの電気をためる性質があります。電気をためる部品を「コンデンサ」といい、ゲートもそれに似ています。 合図の線がつながっていないと、残った電気や周囲の影響で、思わぬONになることがあります。 10kΩ（10キロオーム＝1万オーム）の抵抗は、たまった電気をGNDへ逃がす、小さな穴の役です。

  1. 効くのは「P0がまだ何も出していない間」電源を入れた直後、プログラムが始まるまで。ケーブルを抜いたときも同じ。プログラムが動いて P0 が 0V を出していれば、P0 自身がずっと強い引きとめ役になる。
  2. なぜ 10kΩ なのか抵抗が小さすぎると、ONの間に余分な電流が多く流れます。大きすぎると、合図がないときに電気を逃がしにくくなります。10kΩはよく使われる値の一例で、3Vをかけると0.3mA流れます。回路に合う値は先生が確認します。
  3. これは「静電気よけ」ではないバチッとくる本格的な静電気から部品を守る部品ではない。あくまで、ゆっくりたまる電気を逃がして、思っていない動き（誤作動）を防ぐための係。

回路を守る、2つの部品 先生と確認

上の配線図では省略されています。写真だけでは、保護の有無や十分かどうかまでは判断できません。

  1. ゲート抵抗：合図の電気が、一度に流れすぎないようにする ゲートとP0の間に入れる抵抗です。切りかえる瞬間の電流をおさえる役目があります。必要な値は、MOSFETや切りかえる速さに合わせて選びます。
  2. 還流（かんりゅう）ダイオード：モーターの電流に、逃げ道をつくる モーターのコイルには、電流を流し続けようとする性質があります。急にOFFにすると高い電圧が生じるため、モーターと並列に電流の逃げ道をつくります。一般的な接続では、ダイオードの帯がある側を電源の＋側に向けます。
🧪

「動いた」だけでは、部品を守れているとは限りません。小さなモーターでも、保護を省いてよいとは言い切れません。実物を使う前に、先生が回路図と部品の仕様を確認します。

速さを変える パチパチの正体

🚰

同じ長さの時間を10等分して、5つ分をON、5つ分をOFFにすれば、ONの割合は50％。水門を半分開けるのではなく、開いている時間を半分にするイメージです。
モーターは、OFFの間も回り続けようとします。50％だから回転も必ず半分、とは限りません。この図の回転は目安です。

ONのときに十分通るようにすると、MOSFETで熱になるエネルギーを減らせます。PWMでも、切りかえ時やONの間の発熱はあります。

モーターの速さは、ONにしている時間の割合で調節できます。この方法をPWM（ピー・ダブリュー・エム）といいます。

ONの時間を変える（0〜1023） 512 ／ ひらいている時間 50%

MakeCode JavaScript

// まずOFF。AでON、BでOFF。
pins.digitalWritePin(DigitalPin.P0, 0)
input.onButtonPressed(Button.A, function () {
    pins.digitalWritePin(DigitalPin.P0, 1)
})
input.onButtonPressed(Button.B, function () {
    pins.digitalWritePin(DigitalPin.P0, 0)
})

Python MicroPython

from microbit import *

pin0.write_digital(0)
while True:
    if button_b.is_pressed():
        pin0.write_digital(0)
    elif button_a.is_pressed():
        pin0.write_digital(1)
    sleep(20)

先生が確認した回路で試そう。AボタンでON、BボタンでOFF。合図を出すのはP0、モーターを動かす電流が来るのは電源です。

発展：AボタンでPWMの50％にする

Aボタンの処理を次の2行に置きかえます。BボタンはOFFのままです。0〜1023は電圧の値ではなく、ONの時間の割合を指定する数です。

MakeCode

pins.analogWritePin(AnalogPin.P0, 512)
pins.analogSetPeriod(AnalogPin.P0, 1000)

MicroPython

pin0.write_analog(512)
pin0.set_analog_period(1)

どちらも1周期は1ミリ秒（1秒に1000回）。MakeCodeの1000はマイクロ秒、Pythonの1はミリ秒です。切りかえる速さは、先生が回路に合わせて決めます。

実物で、ここを確かめる 動かす前に

  1. 基板の刻印と、足の向き基板に「S・D・G」などの文字がある。どの足がゲートか、刻印と実物を必ず合わせる。逆に付けると動かない、または壊れる。
  2. どの線がP0かこの装置では、ポートの刻印が左から「GND・3V3・P3-P0」、ケーブルも左から黒・赤・白・黄。だから黄＝P0。ほかのポートにさしたら、プログラムのピン名も変えること。
  3. 約3Vの合図で、十分にONになる部品か型番から説明書を調べます。「しきい値が低い」だけでは不十分。実際にかけるゲート電圧で、ONのときの抵抗が示されているか、先生と確認します。
  4. 電源と、回路を守る部品を確認するモーターが必要とする電流、ゲート抵抗、還流ダイオードなどを確認します。部品やモーターを替えるときも、同じ確認が必要です。
  5. 変だと思ったら、電源を切って先生に伝える回らない、焦げたにおいがする、異常に熱くなるときは使い続けません。熱いかどうかを指で触って試さず、温度の確認は先生に任せます。
🔌

部品選び：「開きはじめ」より「十分に通せるか」。
micro:bitの合図は約3Vです。「ロジックレベル」と呼ばれるMOSFETでも、この電圧で十分にONになるか確認が必要です。 説明書のしきい値 VGS(th) だけでなく、使うゲート電圧でのON抵抗 RDS(on) を先生と調べます。
ON抵抗は「ONのときにも残る、電流の通りにくさ」です。温度やモーターの電流も合わせて、使えるかを判断します。

🧯

配線を変える前に、USBや電池などの電源をすべて外そう。 この装置の図は電源をmicro:bitと共有する例です。別のモーター用電源を使う場合は、プラス側をmicro:bitの3V端子へ直結せず、GNDを共通にするなど、先生が回路を確認します。

教える人へ（このページの前提とねらい）
  • 対象は、通常OFFのエンハンスメント形 Nチャネル MOSFET。矢印は電子ではなく電流の向き（D→S）。
  • 断面図は、空乏層・基板（ボディ）の接続・ボディダイオードを省いた簡略図です。実物の足の並びは製品ごとに異なるため、ページ内でもデータシート確認を促しています。
  • 水模型は定性的なたとえです。漏れ電流、ボディダイオードなど逆向きの電流経路、飽和／線形領域の区別は省いています。
  • 数値（VGS・電池の電圧・電流）は、しきい値3V付近・全開7V付近をイメージした表示用の目安で、特定の型番の実測値ではありません。
  • ゲートは「注ぎつづけなくてよい」＝定常状態でゲート電流ほぼゼロ。ただしスイッチング時はゲート容量の充放電で電流が流れる、という順で扱うと自然です。
  • 発展：しきい値をこえた直後は「半開き」で発熱しやすい → だからスイッチとしてはしっかり開ける、へつなげられます。
  • 授業の進め方：まず予想を言葉にする→つまみを1つずつ変える→観察する→「合図と電源の違い」を自分の言葉で説明する。第5節は発展として折りたたみ、初回は第6節のクイズへ進めます。
  • 第5節の写真・図は既存教材の装置例を引き継いだものです。MOSFETやモーターの型番、実測電流、裏面の部品、保護回路の仕様はこのページだけでは確認できません。ケーブルの色だけで接続を決めず、ポート表示・回路図・導通で確認してください。
  • 単一NチャネルMOSFETの低側スイッチでは、内蔵ボディダイオードだけではモーターの通常の還流経路を作れません。小型モーターでも保護を省けるとは断定できません。還流ダイオードなどの保護と、MOSFET・電源・モーターの定格を確認してから実習してください。
  • プルダウン抵抗は、信号端子が入力状態・未接続などのときにゲートの電圧を定めます。ON中にはこの抵抗にも電流が流れます。「ゲートにほぼ電流が流れない」は、この抵抗を流れる電流を含む駆動回路全体が無消費という意味ではありません。10kΩは一例で、ESD保護の代わりにはなりません。
  • ゲート抵抗はピーク電流や振動を抑えるために検討します。スイッチングが低頻度でも、切りかえ時のピーク電流が小さいとは限りません。ゲート電荷・GPIOの仕様・切りかえ時間から値を選定します。
  • micro:bitの電源余裕は機種・給電方法・動作条件で異なります。公式電源資料ではV1の外付け回路の目安を90mAとし、V2については概要に270mA、実用上の説明に190mAという記載があります。固定の共通上限とせず、使用機種と最悪条件で確認してください。
  • 模型のON表示は通り道の状態、流れの表示は電流の有無です。電源が0でも、ゲートに十分な電圧があればMOSFETはONになり得ます。PWMの回転表示は時間割合に比例させた模式表現で、実測の回転数を示しません。
