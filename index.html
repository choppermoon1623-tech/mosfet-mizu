むずかしそうだけど、まずは「水」で考えれば大丈夫。つまみを動かして、水を流してみよう。

タップすると、続きが出てきます。「ためす」ボタンで、上の実験パネルが動きます。

流れはじめる目安を しきい値（しきいち） といいます。ここは「水門がちょっと開くところ」。 しっかり流すには、部品に合ったゲート電圧が必要です。
水門が全開でも、タンクの水が低ければ流れません。電気も同じで、 通り道をひらくことと本流をおすことは、べつの役割です。
水位さえ保てれば、操作そうに水を注ぎつづける必要はありません。ゲートも、落ち着いた状態では電流がほとんど流れない。 ただし切りかえるときだけ、電気をためたり出したりします。

ほんとうの中では、浮きも水門も動きません。
ゲートの電圧が 電界（でんかい：電気の力がはたらく空間） をつくり、そこに電気の通り道ができます。 ゲートと本流のあいだには、電気を通しにくいうすい膜（まく）があります。だから、 操作の水が本流に混ざらないのと同じで、ゲートの電気は本流に流れこみません。

5

マイクロビットで、動かしてみる

マイクロビットの役目は、水を注ぐこと。つまり「ゲートに電圧をかける係」です。

これが、使う装置 写真

じっさいに教室でつなぐ、そのままの姿です。番号の場所を見くらべてみよう。

🔍

写真から、つながり方が読みとれます。 Groveポートの刻印は左から「GND・3V3・P3-P0」。さしてあるケーブルの色も左から 黒・赤・白・黄。 つまり 黄＝P0（合図）／白＝P3（この基板では未使用）／赤＝3V3（電源）／黒＝GND。 下の図と、同じつながり方です。

じっさいの装置 信号の道すじ

マイクロビット → 拡張ボード → Groveケーブル → 出力アタッチメント基板 → モーター。この順に信号が進みます。

Groveケーブルの4本は、それぞれ役目がちがいます。

  1. 黄：P0の合図ゲートへ。マイクロビットが出すのは電圧だけで、ほとんど電流は流れない。
  2. 白：もう1本の信号（P3）この基板では使っていない。ポートの刻印「P3-P0」の、P3のほう。
  3. 赤：電源（3V3）モーターを回す電流は、こちらから来る。P0（合図）からではない。もとは、マイクロビットにつないだ USB の電気。
  4. 黒：GNDもどり道。ソースにつながって、合図と電流の共通の基準になる。
💡

第1節と、まったく同じ話です。 オレンジの操作そう（黄の線）と、本流のタンク（赤の線）は別。 水門（MOSFET）が、赤い水の道を開け閉めしています。

なぜ、MOSFETをはさむのか 直結できない理由

マイクロビットの端子は、力もちではありません。

くらべるものどれくらい
マイクロビットの端子1本が出せる電流→ 数mA（強く設定しても15mAくらいまで）
ボード全体（エッジコネクタ）の合計→ 190mA まで（micro:bit V2 は 270mA まで）
小さな振動モーターが必要とする電流→ 数十mA〜。回りはじめは、もっと大きい
🚪

だから、端子でモーターを直接まわそうとしてはいけません。 MOSFETは「弱い合図で、太い道を開ける水門」。 マイクロビットは水門を開けるだけ、モーターを回す水は電源から来る——この役割分担が、制御のきほんです。
なおこの装置では、そのモーターの電流も USB からマイクロビットを通ってきています。 だから、上の 190mA（V2は270mA）という合計の中でやりくりすることになります。

この装置のつなぎ方 Nチャネル・下側スイッチ

アタッチメント基板の中身です。モーターの下がわに MOSFET を入れて、地面（GND）へ落とします。電源も、マイクロビット（USB）から。

  1. P0 → ゲートマイクロビットが「水を注ぐ」線。合図（電圧）を送るだけなので、細い線で足りる。
  2. 3V → モーター → ドレインモーターを回す電流の道。もとは USB から来ている電気。
  3. ソース → GNDもどり道。マイクロビットの GND とつながって、合図と電流の共通の基準になる。
  4. 電源は USB からこの装置では、モーターの電流もマイクロビットを通っている。だから、つなげるモーターの大きさに上限がある（ひとつ上の表）。

この装置で、省いてある部品 なぜ動くのか

教科書の回路図には、あと数点ついていることがあります。この装置では省いてあります。何のための部品で、いつ必要になるのかを知っておこう。

  1. ゲート抵抗（220Ωなど） ゲートは、小さなコンデンサのようなもの。切りかえる一瞬だけ、電気がどっと出入りしようとする。抵抗は、その勢いをおさえる役。 省いても動く理由：小さなMOSFETを、ゆっくり切りかえているから。ただし PWM を速くするほど、マイクロビットの端子への負担は増える。
  2. 還流（かんりゅう）ダイオード モーターは、止めた瞬間に逆向きの高い電圧を出す。ダイオードは、その電気の逃げ道。 省いても動く理由：振動モーターが小さく、出てくる電気の量もわずかなので、MOSFET が耐えられる範囲におさまっている。 大きなモーターに替えるときは、必ず入れること。
  3. プルダウン抵抗（10kΩなど） 電源を入れた直後、プログラムが始まるまでの一瞬、P0 はどちらでもない状態になる。その間、ゲートをきちんと 0V に引っぱっておく役。 目印：電源を入れた瞬間に一瞬ブルッと震えるなら、これが無いサイン。
🧪

部品を減らすと、回路はすっきりして分かりやすくなります。そのかわり、「小さいモーターだから成り立っている」という前提がつきます。 つなぐ相手を大きくするときは、この前提がくずれる——という見方を持てると、もう立派な設計です。

速さを変える パチパチの正体

MOSFETは「半開き」が苦手（熱くなる）。だから、速く開け閉めして平均で調節します。

analogWritePin の値 512 ／ ひらいている時間 50%

MakeCode JavaScript

// ON / OFF だけ
pins.digitalWritePin(DigitalPin.P0, 1)
pins.digitalWritePin(DigitalPin.P0, 0)

// 速さを変える（PWM）
pins.analogSetPeriod(AnalogPin.P0, 1000)
pins.analogWritePin(AnalogPin.P0, 512)

Python MicroPython

from microbit import *

# ON / OFF だけ
pin0.write_digital(1)
pin0.write_digital(0)

# 速さを変える（PWM）
pin0.set_analog_period(1)
pin0.write_analog(512)

値は 0〜1023。周期は MakeCode がマイクロ秒、Python がミリ秒（最小1ms）で指定します。 モーターが「ピー」と鳴くときは、周期を短くしてみよう。

実物で、ここを確かめる 動かす前に

  1. 基板の刻印と、足の向き基板に「S・D・G」などの文字がある。どの足がゲートか、刻印と実物を必ず合わせる。逆に付けると動かない、または壊れる。
  2. どの線がP0かこの装置では、ポートの刻印が左から「GND・3V3・P3-P0」、ケーブルも左から黒・赤・白・黄。だから黄＝P0。ほかのポートにさしたら、プログラムのピン名も変えること。
  3. MOSFETの刻印を読んで、しきい値をしらべる部品の表面の文字で検索して、3.3Vでしっかり開くタイプ（ロジックレベル）かを確認する。
  4. 動かしてすぐ、指でさわってみるMOSFETがほんのり温かい程度ならOK。熱いときは「半開き」のサイン。すぐ電源を切る。
  5. つなぐ相手を変えるときは、部品を足すこの装置は、小さな振動モーターだからゲート抵抗も還流ダイオードも省けている。大きなモーターやソレノイドに替えるときは、上の「省いてある部品」を読みなおすこと。
🔥

いちばんの落とし穴：マイクロビットは 3.3V しか出せません。
しきい値の高い MOSFET だと、3.3V では半開きのまま。回らない、または部品がとても熱くなります。 これは第3節「① 水がちょっとあるだけでは、ONにならない」そのもの。 ロジックレベル（3.3V でしっかり開くタイプ）の N チャネル MOSFET を選んでください。 データシートでは、しきい値 VGS(th) の値と、VGS＝2.5V や 3V のときの抵抗（RDS(on)）が書いてあるかを見るのが目印です。

🧯

そのほかの注意：MOSFETがさわれないほど熱いときは、すぐ電源を切る（半開きのサイン）。 モーターの電源とマイクロビットの電源は分け、GND だけを共通に。配線を変えるときは、かならず電池を外してから。

ひとことで言うと
MOSFETは「電圧で、電流をあやつる部品」。
教える人へ（このページの前提とねらい）
  • 対象は、通常OFFのエンハンスメント形 Nチャネル MOSFET。矢印は電子ではなく電流の向き（D→S）。
  • 断面図は、空乏層・基板（ボディ）の接続・ボディダイオードを省いた簡略図です。実物の足の並びは製品ごとに異なるため、ページ内でもデータシート確認を促しています。
  • 水模型は定性的なたとえです。漏れ電流、ボディダイオードなど逆向きの電流経路、飽和／線形領域の区別は省いています。
  • 数値（VGS・電池の電圧・電流）は、しきい値3V付近・全開7V付近をイメージした表示用の目安で、特定の型番の実測値ではありません。
  • ゲートは「注ぎつづけなくてよい」＝定常状態でゲート電流ほぼゼロ。ただしスイッチング時はゲート容量の充放電で電流が流れる、という順で扱うと自然です。
  • 発展：しきい値をこえた直後は「半開き」で発熱しやすい → だからスイッチとしてはしっかり開ける、へつなげられます。
  • 第5節の装置は、ゲート抵抗・還流ダイオードを省いた構成です。低側スイッチでは、MOSFETのボディダイオードは還流経路になりません（遮断時にドレインが正へ振れるため逆バイアス）。小さな振動モーターで成立しているのは、誘導性エネルギーが小さく素子のアバランシェ耐量の範囲に収まるためで、負荷を大きくする場合は還流ダイオードが必須です。
  • ゲート抵抗を省くと、スイッチング時のピーク電流がそのまま端子に流れます。低速なON/OFFなら実用上問題になりませんが、PWM周波数を上げるほど負担が増えます。ゲート電荷の充放電＝「切りかえるときだけ電気が出入りする」（第3節③）の実地版として扱えます。
  • 電源は USB →micro:bit の 3V3。モーター電流もエッジコネクタの制限（190mA、V2は270mA）の内側でやりくりすることになります。
  • 参考：東芝「NチャネルMOSFETの動作原理」／東芝「必要なゲート電圧」／Infineon「Gate drive for power MOSFETs」
