## 使い方

つまみは2本だけ。**そうさつまみ**（操作そうの水位＝ゲートの電圧）と **ポンプつまみ**（水の高さ＝電池の電圧）を動かすと、左の「水の世界」と右の「電気の世界」が同時に動く。ボタンで「ゆっくりON」「OFFにもどす」「パチパチ切りかえ」「ポンプだけ止めてみる」を試せる。授業では、まず水位だけを上げて**いつ流れ出すか**を予想させると入りやすい。

| 節 | 内容 |
|---|---|
| 1 実験パネル | 水門と水車／回路とモーターを、同じつまみで同時に動かす。水位・ひらき・流量・V<sub>GS</sub>・電圧・電流をリアルタイム表示 |
| 2 3つの端子 | G・D・S の役割と、水の世界との対応表 |
| 3 3つのポイント | しきい値／おす力／注ぎつづけなくてよい。各項目から実験パネルを操作できる |
| 4 たとえから、本物へ | 外がわ（TO-220 の足 G・D・S をタップ）と、中がわ（断面図。電子が集まり通り道ができる） |
| 5 マイクロビットで動かす | じっさいの装置の信号の道すじ／なぜ直結できないか／つなぎ方／PWM（波形と回転が連動） |
| 6 30秒チェック | 3問。選ぶとその場で答え合わせ |

## しくみのメモ

- しきい値は「**くさりのたるみ**」で表現している。浮きが上がってもくさりが張るまで水門は動かず、張ってから持ち上がる。全開後は浮きが水没して止まる（水門の可動量と浮きの可動域を一致させてあるので、片方だけ変えると破綻する）。
- モーターは水車に置き換え、回転は電流に比例。水車は左側に水を受けるので反時計回り。
- 断面図は第1節と同じ状態で動く（節内のつまみは上のつまみと相互に同期）。

## マイクロビットで動かす節（第5節）について

勤務校の構成（micro:bit ＋ 拡張ボード ＋ Grove ケーブル ＋ 自作の出力アタッチメント基板 ＋ 振動モーター）に合わせてある。ねらいは、**1本の Grove ケーブルの中を「細い合図（黄＝P0）」と「太い電流（赤＝3V3・黒＝GND）」が別々に走っている**ことを見せ、第1節の「操作する水と、流れる水は別」と重ねること。

- 端子の電流は micro:bit 公式（tech.microbit.org）の値：1ピンあたり数mA（V2 の高ドライブでも 15mA 程度）、エッジコネクタ全体で 190mA（V2 は 270mA）。
- MakeCode / MicroPython のコード例。`analogWritePin` は 0〜1023、周期は MakeCode がマイクロ秒・MicroPython がミリ秒（最小1ms）。**既定の周期は公式に明記がないため、ページでも断定していない。**
- 最大の注意として「micro:bit は 3.3V しか出せない → しきい値の高い MOSFET では半開き → 発熱」を赤枠で置いた。第3節①の実地版。
- 特定の型番は書いていない。実物の刻印を読んでデータシートで確認する、という手順に倒してある。

## 教材としての前提

- 対象は、通常OFFの**エンハンスメント形 Nチャネル MOSFET**。矢印は電子ではなく**電流**の向き（D→S）。
- 水模型は定性的なたとえ。漏れ電流・ボディダイオード・飽和／線形領域の区別は省略。
- 表示される数値（V<sub>GS</sub>・電圧・電流）は、しきい値3V付近・全開7V付近をイメージした**表示用の目安**で、特定の型番の実測値ではない。
- 実物の足の並びは製品ごとに異なるため、パッケージ図に型番は印字せず、ページ内でデータシート確認をうながしている。
